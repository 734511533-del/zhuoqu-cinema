# 拙趣映画 · Zhuoqu Cinema

把影视氛围与日常场景，画成有纸感、留白和一点笨拙可爱的手绘插画。

一个可复用的生图技能（Skill）：将场景与情绪转译为提示词，并调用所在环境的图像生成工具完成创作与局部修改。

## 风格特点

- **纸感与粗粝笔触**：暖白纤维纸、干水粉、蜡笔、断续细线，保留自然的漏白与颜料边缘。
- **克制配色与留白**：少量低饱和主色，搭配小面积强调色；默认竖版 3:4，可按用途调整。
- **自然的拙趣**：人物姿态略拘谨、五官简省，身体比例与双人身高差保持自然。
- **影视氛围转译**：提取少量场景线索和人物关系，适用于电影、剧集与日常生活主题。
- **局部修改**：用户认可整体时，只改指定细节，尽量保留构图、配色和手绘质感。

“喜茶式拙趣”仅是审美参考，不默认添加茶杯、包装、品牌标志或广告文案。本项目与喜茶及相关影视作品无官方关联。

## 怎么用

在支持自定义技能的 AI 工具中导入本仓库，或将技能文件放入该工具的技能目录。实际生图需要宿主环境提供图像生成能力；本仓库不包含独立生图模型或 API 服务。

在 Codex 本地环境中，可将仓库克隆到技能目录：

```bash
git clone https://github.com/734511533-del/zhuoqu-cinema.git ~/.codex/skills/zhuoqu-cinema
```

私有仓库需要具有访问权限并完成 GitHub 身份验证。其他工具请使用各自支持的技能导入方式。

安装后，直接描述想画的内容：

> 用 $zhuoqu-cinema 画一张《鬼怪》海边相遇氛围的拙趣插画，保留红围巾和冬日海面，不加文字。

> 用拙趣映画画一个雨天等公交的人，灰绿和米白配色，安静里带一点幽默。

> 其他都不错，只把两个人的身高差缩小，保留原来的构图和笔触。

也可以指定横版、封面用途、主体位置、强调色或需要保留的细节。默认生成一张；没有图像工具时，可输出可复用提示词。

## 创作起点

这套方法来自一次《鬼怪》氛围插画的迭代：从品牌产品摄影，调整为暖白纸上的朴拙手绘，再修正过大的双人身高差。它保留可复用的审美与修改规则，场景可以自由更换。
