# 拙趣映画 · Zhuoqu Cinema

**简体中文** | [English](README.en.md)

把影视氛围与日常场景，画成有纸感、留白和一点笨拙可爱的手绘插画。

一个面向国内外生图环境的可复用技能（Skill）：不绑定 GPT 或特定厂商，根据实际能力输出通用提示词、简化提示词，或调用所在环境的工具完成生图。

## 风格特点

- **纸感与粗粝笔触**：暖白纤维纸、干水粉、蜡笔、断续细线，保留自然的漏白与颜料边缘。
- **克制配色与留白**：少量低饱和主色，搭配小面积强调色；默认竖版 3:4，可按用途调整。
- **自然的拙趣**：人物姿态略拘谨、五官简省，身体比例与双人身高差保持自然。
- **影视氛围转译**：提取少量场景线索和人物关系，适用于电影、剧集与日常生活主题。
- **局部修改**：用户认可整体时，只改指定细节，尽量保留构图、配色和手绘质感。

“喜茶式拙趣”仅是审美参考，不默认添加茶杯、包装、品牌标志或广告文案。本项目与喜茶及相关影视作品无官方关联。

## 怎么用

在支持自定义技能的 AI 工具中导入本仓库，或将技能文件放入该工具的技能目录。不支持技能导入的工具，可以直接复制 SKILL.md 中的简化提示词使用。实际生图需要宿主环境提供图像生成能力；本仓库不包含独立生图模型或 API 服务。

在 Codex 本地环境中，可将仓库克隆到技能目录：

```bash
git clone https://github.com/734511533-del/zhuoqu-cinema.git ~/.codex/skills/zhuoqu-cinema
```

本仓库已公开，可直接浏览、下载或通过上述 HTTPS 地址克隆，无需私有仓库访问授权。其他工具请使用各自支持的技能导入方式。

安装后，直接描述想画的内容：

> 用 $zhuoqu-cinema 画一张《鬼怪》海边相遇氛围的拙趣插画，保留红围巾和冬日海面，不加文字。

> 用拙趣映画画一个雨天等公交的人，灰绿和米白配色，安静里带一点幽默。

> 其他都不错，只把两个人的身高差缩小，保留原来的构图和笔触。

也可以指定横版、封面用途、主体位置、强调色或需要保留的细节。默认生成一张；没有图像工具时，可输出可复用提示词。

## 创作起点

这套方法来自一次《鬼怪》氛围插画的迭代：从品牌产品摄影，调整为暖白纸上的朴拙手绘，再修正过大的双人身高差。它保留可复用的审美与修改规则，场景可以自由更换。

## 跨模型使用

核心规则在 `SKILL.md`，可以独立阅读。 `agents/openai.yaml` 仅是支持该格式的宿主界面配置，其他工具可以忽略，无需 OpenAI 账号才能理解或使用提示词。

| 环境能力 | 用法 |
| --- | --- |
| 支持技能与生图调用 | 加载技能，按当前工具规范生成 |
| 只能粘贴提示词 | 复制标准版或简化版，不需要技能调用标记 |
| 模型容易漏细节或能力未知 | 用简化版，先保主体、构图和配色，再补质感 |
| 只能对话、不能生图 | 让它按规则整理提示词，再交给生图工具 |
| 不支持参考图或局部编辑 | 只能重绘，无法保证其他部分完全不变 |

### 可直接复制的简化提示词

> 两个成年人在灰蓝海边面对面站着，一人黑外套，一人米白外套戴红围巾，两人身高接近。人物在画面下方，上方大片暖白空白。粗糙水粉手绘，颜色少，人物比例自然。无文字、无标志。

替换主体、场景和颜色即可用于其他主题。优先用单一语言、短句和具体位置描述；默认不依赖精确数值、权重符号、种子或专属参数。不以品牌或国别判断能力。

### 稳定性边界

技能通过固定风格要点、降低提示词复杂度和单项纠偏减少跑偏。不同模型的画质、构图遵循与编辑能力仍有差别，不能保证相同输出。本次更新检查了规则结构和文本交接路径，尚未完成多个实际生图平台的对照测试。
